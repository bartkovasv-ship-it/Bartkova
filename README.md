
# Бот - трекер привычек

## Описание

Telegram-бот для отслеживания привычек.
Пользователь может создавать привычки, отмечать их выполнение
и смотреть статистику своего прогресса.
Интерфейс userfriendly

## Установка

Клонировать проект:

git clone https://github.com/username/habit-tracker-bot.git


Установить зависимости:

pip install -r requirements.txt

## Запуск

1. Запустить программу main.py
2. В поисковике Telegram найдите бота @EveryTimeADay_bot
2. Откройте бота 
3. Нажмите /start

## Входные данные

Пользователь взаимодействует с ботом через кнопки Telegram и вводит:

1. название новой привычки
2. время ежедневного напоминания в формате ЧЧ:М(например, 09:00)

## Результат работы

После выполнения действий пользователь получает:

- список своих привычек
- подтверждение успешного создания привычки
- подтверждение выполнения привычки
- статистику по количеству выполнений каждой привычки
- текущую серию выполнения (streak)
- автоматические напоминания в заданное время

## Пример работы
Пользователь: /start

Бот:
Привет, Имя пользователя!

[Создать новую привычку]
[Мои привычки]
[Удалить привычку]
[Статистика]

Пользователь нажимает:
Создать новую привычку

Бот:
Напиши название привычки.

Пользователь:
Пить воду

Бот:
Во сколько напоминать? (например, 09:00)

Пользователь:
09:00

Бот:
✅ Привычка "Пить воду" добавлена.
⏰ Напоминание установлено на 09:00.

## Инструменты и библиотеки
Python 3
pyTelegramBotAPI
SQLite3
threading
datetime
time

## Роль ИИ

При разработке проекта использовался ChatGPT как помощник в обучении программированию. С его помощью были изучены возможности библиотеки pyTelegramBotAPI, принципы работы с базой данных SQLite, обработка callback-кнопок, поиск и исправление ошибок, а также реализованы отдельные функции бота. Основной код был написан, протестирован и адаптирован автором проекта.

## Ограничения

- Не учитывает, что время в сутках не более 24 часов и в часе не более 60 минут
- Если отметить одну привычку два раза за день функция "Серия" (streak) собьётся

## Идеи для развития

- Возможность изменять время напоминаний
